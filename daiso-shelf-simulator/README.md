# 다이소 바구니 선반 시뮬레이터

선반 안쪽 규격(폭 · 깊이 · 높이)을 넣으면 **다이소몰에서 실제로 파는 수납 바구니 96종** 중 딱 맞는 것을 골라주고,
앞 / 옆 / 위 세 방향 미리보기에서 직접 배치해보는 정적 웹 앱입니다.
인스타그램 `@lightsu.home` 의 "다이소 바구니 선반 미리보기" 릴스에서 착안했습니다.

- 빌드 도구 없음. `index.html` 하나만 열면 바로 동작합니다.
- 외부 CDN · 웹폰트 · 프레임워크 의존 없음 (상품 썸네일만 다이소몰 이미지 서버 사용).
- 영수증은 브라우저 안에서 Canvas 2D 로 그려 PNG 로 저장합니다(오프라인에서도 동작).

## 기능

**1. 선반 규격 입력**
- 폭 / 안쪽 깊이 / 높이(cm) 입력, 자주 쓰는 프리셋 6종(60×35×40, 60×30×35, 80×35×40, 90×40×45, 45×30×30, 120×40×45)

**2. 맞춤 추천 & 필터**
- 입력한 선반에 들어가는 바구니를 **여유 공간이 적은 순(딱 맞는 순)** 으로 정렬
- 필터: 전체 / 천원템 / 팬트리 / 브릭스 / 메쉬 / 냉장고·주방 / 직사각 / 리빙박스
- 품명 · 품번 키워드 검색, "선반에 들어가는 것만" 토글
- 카드마다 품명, 규격(가로×세로×높이), 품번, 가격, 절약 여유 배지, 썸네일(클릭 시 다이소몰 상품 페이지)

**3. 선반 미리보기 (3면 뷰)**
- `앞에서`(폭×높이) · `옆에서`(깊이×높이) · `위에서`(폭×깊이) 탭
- 드래그로 좌우 이동, 다른 바구니 위로 쌓기(충돌·경계·높이 검사, 0.5cm 스냅, 모서리 자석 스냅)
- 바구니를 누르면 하단 툴바: `돌리기`(가로↔세로 90°), `눕히기`(높이↔깊이), `앞뒤 2줄`(깊은 선반에 앞뒤로 복제), `제거`
- 상단: `되돌리기`(최대 60단계), `전부 내리기`
- 실시간 수치: 남은 폭 / 깊이 여유 / 개수·합계 / 가장 높은 칸과 위로 남는 높이
- 모바일에서는 화면 아래 요약 바(개수·합계)로 바로 미리보기·영수증으로 이동
- ⌨️ 선택 후 방향키(0.5cm, Shift=5cm) 이동, Delete 제거, Esc 선택 해제
- 배치 상태는 브라우저(localStorage)에 자동 저장

**4. 품번 영수증**
- 담은 바구니를 품번 기준으로 묶어 품명 · 품번 · 단가 · 수량 · 소계 · 총합계 · 선반 규격을 한 장에
- Canvas 2D 로 2160px 폭 고해상도 PNG 저장

## 실행

```bash
# 1) 그냥 열기
open index.html            # macOS
# 또는 파일 탐색기에서 index.html 더블클릭

# 2) 로컬 서버(권장)

# → http://localhost:8000
```

## 데이터

`data/baskets.json` (앱은 같은 내용의 `data/baskets.js` 를 읽습니다)

- **출처**: 다이소몰 <https://www.daisomall.co.kr> — 검색 결과와 상품 상세 정보(품번 · 가격 · 카테고리 · 사이즈 표기)
- **수집일**: 2026-11-22
- **수록**: 96종 (수납/정리 > 바구니류 · 수납정리함, 주방 > 냉장고정리바구니 등에서 규격이 확인되는 상품만)
- **규격 기준**: 상품 페이지의 `사이즈` 표기에 **가로 / 세로(깊이) / 높이** 로 적힌 값을 그대로 사용했습니다.
  사이즈 표기가 없거나, 옵션마다 규격이 달라 한 값으로 정할 수 없는 상품, 묶음(대량) 상품은 제외했습니다.
  예를 들어 `팬트리 수납 바구니 3호`는 상품 페이지에 라벨 없는 값(약 16.5 / 26.5 / 35cm)만 있어
  가로·세로·높이를 확정할 수 없으므로 넣지 않았습니다.
- **필드**

| 필드 | 의미 |
| --- | --- |
| `id` | 품번 (상품 페이지의 `품번:` 표기) |
| `pd` | 다이소몰 상품번호 — 품번과 1글자 다를 수 있음 |
| `w` / `d` / `h` | 가로 / 세로(깊이) / 높이 (cm) |
| `price` | 판매가(원) |
| `series` | 시리즈 태그(팬트리, 브릭스, 메쉬, 냉장고, 직사각 …) |
| `cat` | 다이소 카테고리 경로 |
| `soldout` | 수집 시점 일시품절 여부 |
| `src` | 규격 출처 `label`(상품 페이지 사이즈 표) / `desc`(상품 설명의 사이즈 문구) |
| `url` | 상품 페이지 주소 |

- 품번과 다이소몰 상품번호(`pd`)가 1글자 다른 상품이 있습니다(예: 품번 1056997 / 상품번호 1056996). 링크는 상품번호 기준입니다.
- 가격·재고는 수집 시점 기준이며 지금과 다를 수 있습니다. 매장 실측과 1~2cm 오차가 날 수 있으니 구매 전 상품 페이지를 확인하세요.
- 이 앱은 다이소와 무관한 개인 제작 도구입니다.

## 파일 구조

```
daiso-shelf-simulator/
├── index.html              # 화면 마크업
├── assets/
│   ├── styles.css          # 웜 베이지 · 에스프레소 테마, 모바일 우선 반응형
│   └── app.js              # 배치 엔진 · 3면 뷰 · 영수증 캔버스 · 저장
├── data/
│   ├── baskets.js          # window.DAISO_DATA (앱이 읽는 파일)
│   └── baskets.json        # 같은 데이터(JSON)
├── scripts/
│   └── collect_daiso.py    # 다이소몰 재수집 스크립트(검색 → 상세 → 규격 파싱)
└── tests/
    ├── validate_data.py    # 데이터 무결성 검사(품번·규격·가격·URL)
    └── smoke_test.py       # quickjs + 최소 DOM 으로 앱을 실제 실행하는 스모크 테스트
```

## 테스트

```bash
python3 tests/validate_data.py     # 데이터 검사 (의존성 없음)
pip install quickjs
python3 tests/smoke_test.py        # 앱 실행 검사 31개
```

`smoke_test.py` 는 HTML 을 파싱해 가짜 DOM 을 만들고 `app.js` 를 실제로 실행합니다.
카탈로그 렌더, 담기, 겹침 검사, 쌓기, 되돌리기, 규격 변경, 선택 툴바(돌리기·눕히기·2줄·제거), 방향키 이동, 영수증 캔버스까지 확인합니다.
